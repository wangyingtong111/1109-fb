# 大公共偏置下 Rumale 距离矩阵数值损失诊断

- 被测代码：`rumale-core/lib/rumale/pairwise_metric.rb`
- 诊断脚本：`rumale-core/diagnostics/large_bias_distance_loss.rb`（纯 Ruby，仅依赖 `numo-narray-alt`）
- 复跑方式：`ruby rumale-core/diagnostics/large_bias_distance_loss.rb`，全部断言通过时退出码为 0
- 环境：Ruby 4.0.7 (x64-mingw-ucrt)，Numo::DFloat = IEEE-754 Float64

## 1. 问题机理：展开式平方距离 + 负数截断

`squared_error` 不直接做 `(x-y)^2`，而是走展开式（`pairwise_metric.rb:40-48`）：

```
err = -2 * x.dot(y^T) + ||x||^2(列) + ||y||^2(行)
err = Numo::DFloat.maximum(err, 0)      # 负数一律截断为 0
```

`euclidean_distance` 是 `sqrt(squared_error.abs)`，`rbf_kernel` 是 `exp(-gamma * squared_error)`。
当所有坐标整体平移一个大常数 B（本诊断取 B=1e10），三个分量都达到 B^2=1e20 量级，
而该量级的 1 个 ULP = **16384**。三个相近大数相减属于典型的灾难性抵消，
结果的有效精度被大项 ULP 锁死，真实距离（量级 1~16）被分量各自的舍入残差淹没。

## 2. 最早的数值损失定位（以 (B,0) vs (B+1,0) 为例）

直接相减 `(B+1)-B = 1` 完全无损；损失从平方/点积分量进入 1e20 量级开始：

| 分量 | 整数真值 | Float64 存储值 | 舍入残差 |
|---|---|---|---|
| x·x = B² | 100000000000000000000 | 100000000000000000000.0 | 0 |
| y·y = (B+1)² | 100000000020000000000 | 100000000019999997952.0 | 存储−真值 = −2048 |
| x·y = B(B+1) | 100000000010000000000 | 100000000010000007168.0 | 存储−真值 = +7168 |

三个大项按 `-2xy + xx + yy` 合并后得到 **raw = −16384.0**（真值应为 1）。
即损失在展开式的平方/点积与加减合并阶段已经发生，`sqrt`、`exp` 只是下游受害者。

## 3. 基线与偏置对照（gamma=1 的 RBF）

无偏置时展开式无损，结果与理论一致：

| 点对 | 平方距离 | 欧氏距离 | RBF(gamma=1) |
|---|---|---|---|
| (0,0) vs (1,0) | 1 | 1 | exp(−1) = 0.3678794412 |
| (0,0) vs (0,0)（真重复点） | 0 | 0 | exp(0) = 1 |

整体平移后（坐标差保持不变）：

| 点对（1D，第二坐标为 0） | 截断前 raw | 截断后平方距离 | 欧氏距离 | RBF(gamma=1) | 理论 RBF |
|---|---|---|---|---|---|
| (B,0) vs (B,0)（自身/对角） | 0.0（真零） | 0 | 0 | 1.0 | 1.0 |
| (B,0) vs (B+1,0)，δ=1 | **−16384.0** | 0 | 0 | 1.0 | exp(−1)=0.3679 |
| (B,0) vs (B+2,0)，δ=2 | **0.0**（舍入零） | 0 | 0 | 1.0 | exp(−4)=0.0183 |
| (B,0) vs (B+4,0)，δ=4 | **+16384.0**（膨胀） | 16384 | 128 | 0.0（下溢） | exp(−16)=1.13e−7 |

## 4. 三类零的区分及对 RBF 的影响

1. **真零（对角 / 真重复点）**：截断前 raw 恰好为 0.0。距离 0、RBF=1，语义正确。
2. **截断前已舍入为零**：raw 在进入 `maximum` 之前就抵消成 0（如 δ=2，真值 4）。
   不同点被判为同点，RBF 被顶到上限 **1.0**（理论 0.0183）。
3. **负数被截断**：raw 为负（如 δ=1，raw=−16384，真值 1），被 `maximum(raw,0)` 抹成 0。
   同样报距离 0、RBF=1.0（理论 0.3679）。负值永远到不了 `sqrt`，因此 `euclidean_distance`
   里的 `.abs` 对截断后的矩阵是冗余的。
4. （附带）**正向舍入膨胀**：raw 为正但被夸大量化到 16384 的整数倍（如 δ=4：16→16384，
   欧氏距离 4→128），`exp(−16384)` 在 Float64 直接下溢为 **0.0**，相似度被压到下限。

净效应：RBF 矩阵的取值被挤向两个极端——假零把核值抬成 1.0（假高相似），
膨胀把核值压成 0.0（假零相似/下溢），中间的真实区分度全部丢失。

## 5. 显式 X/Y 与省略 Y 的自身比较

- 省略 Y（`squared_error(X)`）内部令 `y = x`，与显式传入数值相同的独立 Y 走同一条展开式，
  诊断脚本断言两者输出逐元素相等。
- 四点自身比较（偏移 0/1/2/4）的 4×4 矩阵：**对角 4 个真零**；12 个非对角元素中
  4 个负数截断假零、4 个舍入零、4 个正向膨胀（实测见脚本第 4 节打印的 raw / clamped / RBF 矩阵）。
- 二维整体平移 `(B,B)` 的 3 点矩阵（含 1 对真重复点）两个坐标的残差恰好都抵消，
  raw 全矩阵为 0：非对角 6 个全是假零，与真重复点在输出上无法区分，RBF 全为 1.0。

## 6. 规模化普查

131 个偏置 1D 点 B..B+130，共 17030 个非对角有序点对：

- 截断前为负、被截断成 0：**3050** 个
- 截断前已舍入为 0：**8146** 个
- 假零合计 **11196 个（65.74%）**；截断后矩阵零元素 11327 个（仅 131 个对角真零）
- 其余 5834 个为正向膨胀，RBF 普遍下溢为 0
